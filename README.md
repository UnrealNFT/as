# Miam'Monde 🌍

Jeu de plateau familial 3D avec Three.js.

## Règles
- Lance les dés, avance sur le festival gastronomique mondial
- Achète des stands (Pizza Napoli, Tokyo Ramen, Mexico Tacos...)
- Pioche des cartes chance, paie la douane, fais une pause goûter
- Sois le premier à posséder 8 stands ou atteindre 5000 crédits

## Lancer
Ouvre `index.html` dans un navigateur moderne.
